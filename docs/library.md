# The notebook's textfiles

The notebook doesn't explain how to get into each system. Instead it names the real
textfile that does. Callers read the file, try what it says, and get in. On
City of Thieves those files are in the board's own file areas. On your board,
gather them into one file area and set `library=<area name>` in the door's
args (see the README), and the notebook sends players there.

Without the setting, CARRiER still works: each page names the file and says
to look in any textfile archive.

Most of these are on [textfiles.com](http://www.textfiles.com/), in its
hacking, phreaking and magazines sections. The three marked *HC2* are from
*The Hacker Chronicles II* CD-ROM (1994). File names are as the notebook gives
them; some archives have them in a different case.
